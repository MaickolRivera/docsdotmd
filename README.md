# DOCSmd

Plataforma de documentación privada tipo GitBook/Mintlify: cada **organización** tiene **espacios** (pestañas) con **páginas en markdown** y componentes visuales. Solo los miembros autorizados entran.

## Stack

Next.js 16 (App Router, TypeScript estricto) · Tailwind CSS 4 + shadcn/ui · pnpm.

## Puesta en marcha

1. `pnpm install`
2. `pnpm dev` y entra en http://localhost:3000

## Scripts

`pnpm dev` · `pnpm build` · `pnpm lint` · `pnpm typecheck`
